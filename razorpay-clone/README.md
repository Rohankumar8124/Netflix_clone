# Razorpay Clone

A front-end clone of the Razorpay homepage built with plain HTML, CSS and JavaScript.

## Run it

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000

## What's inside

- `index.html` - page structure (navbar, hero, payments suite, banking, stats, testimonials, CTA, footer)
- `style.css` - styling, responsive layout, animations
- `script.js` - mobile menu, animated counters, testimonial slider, demo checkout modal

Educational project. Not affiliated with Razorpay. No real payments are processed.
